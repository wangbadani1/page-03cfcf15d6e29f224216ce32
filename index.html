服务规格说明

Worldnod 运行于自建中继网络，提供基于 Shadowsocks 与 V2Ray 协议的加密传输通道。以下为系统层面的基础参数。

传输协议

Shadowsocks-R, VMess, VLESS

加密方式

AES-256-GCM, ChaCha20-Poly1305

路由模式

分流模式, 全局模式, 自定义规则

重置周期

自然月计费，每月1日 00:00 (UTC+8)

客户端部署指引

Worldnod 订阅链接兼容主流第三方代理客户端。请根据设备系统选择对应软件，导入订阅地址即可完成配置。

Windows
Clash for Windows / v2rayN 支持图形化界面配置。导入订阅地址后，在配置文件列表中选择 Worldnod 节点组，启用系统代理即可。
macOS
ClashX Pro / Quantumult X 推荐使用 ClashX Pro 获取完整的分流规则支持。Quantumult X 需手动配置节点订阅与规则订阅。
Android
Clash for Android / Shadowsocks 支持 SSR 与 V2Ray 协议。在配置页面点击加号，选择从 URL 导入，粘贴订阅地址。
iOS
Shadowrocket / Quantumult X 需通过非中国区 Apple ID 下载。在 App 内选择添加订阅，输入 Worldnod 提供的节点地址。
路由器
OpenWrt / Padavan 支持在搭载 OpenWrt 系统的路由器上部署。需安装 Clash 或 V2Ray 插件，配置文件从订阅地址更新。

常见问题排查

网络连接异常时，请按以下步骤进行排查。若问题持续，请提交工单并附上客户端日志。

订阅链接无法更新或显示为空？
检查客户端是否能直接访问订阅地址。若本地网络无法解析，可尝试切换至其他网络环境或使用加密 DNS。确认订阅链接未过期，若链接失效请在用户中心重新生成。
连接成功但无法访问部分网站？
检查客户端的路由规则配置。确认当前处于"规则模式"而非"直连模式"。若特定网站无法加载，尝试清除浏览器 DNS 缓存，或在客户端中手动将该域名加入代理规则。
设备提示流量已耗尽但实际未达上限？
系统按传输字节统计流量，包含协议开销与重传数据，实际可用流量可能略少于标称值。若差距过大，检查是否有后台应用自动更新消耗流量，或更换节点确认是否单节点统计异常。
多设备同时使用时频繁掉线？
确认当前套餐的设备并发数限制。基础版限 3 台，旗舰版限 5 台，团队版限 20 台。超出限制时，新设备接入会挤掉旧连接。如需增加并发数，请升级至更高层级套餐。
IPLC 专线节点如何启用？
IPLC 专线节点仅对旗舰版及以上套餐开放。在客户端节点列表中，名称带有"IPLC"前缀的即为专线节点。选择该节点即自动启用专线传输，无需额外配置。
如何获取故障排查所需的日志文件？
Windows 端在 Clash for Windows 的 General 页面点击 Logs；macOS 端在 ClashX 菜单栏选择"导出日志"；移动端在 App 设置内查找诊断或日志选项。提交工单时请附上最近 24 小时的日志文本。
